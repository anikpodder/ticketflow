# AI Usage Documentation

## AI Tools Used

**ChatGPT**

ChatGPT was used as an AI development assistant throughout the TicketFlow project.

## How AI Was Used

- Brainstorming project architecture and implementation approaches.
- Understanding design patterns and SOLID principles.
- Debugging and troubleshooting development issues.
- Reviewing code and identifying potential edge cases.
- Understanding database transactions, concurrency, and idempotency.
- Assistance with technical documentation.

## What I Did Myself

I was responsible for:

- Setting up the project and development environment.
- Implementing and integrating application features.
- Configuring the database, authentication, and deployment.
- Reviewing AI-generated suggestions.
- Testing application workflows and verifying behavior.
- Making implementation decisions and fixing issues.

## AI Limitations and Verification

AI-generated suggestions were not accepted blindly. I reviewed the suggested code, checked whether it matched the project's requirements, and tested important application workflows.

One important lesson was that AI-generated solutions can contain incorrect assumptions or implementation details. Therefore, manual verification and understanding were essential.

## Future Improvements

With more time, I would improve automated testing, background job processing, monitoring, and production-grade payment integration.
